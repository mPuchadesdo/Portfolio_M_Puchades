
# Análisis de datos de una clínica de fisioterapia

## Descripción
Llevo años trabajando en centros de fisioterapia pequeños, de entre 4 y 8 empleados. Suelen ser centros dirigidos por un profesional sanitario, un fisioterapeuta, que tiene que hacer su trabajo y además ser empresario. Por ello, creo que es interesante mostrar qué pueden enseñarnos los datos para poder estudiar con detenimiento qué líneas de mejora se pueden seguir para mejorar el negocio y ofrecer un mejor servicio basándonos en la información de la que disponemos. 
Todos los datos que se van a utilizar en este pequeño proyecto son sintéticos. Ni los pacientes ni la clínica de fisioterapia existen. Es únicamente una demostración de cómo la creación de una buena base de datos (en este caso creada mediante MySQL), un análisis profundo de esta y un buen dashboard (con PowerBI) pueden llegar a cambiar las decisiones que se toman en un centro pequeño.
